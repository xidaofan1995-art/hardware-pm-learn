# Hardware PM Lab｜智能硬件产品开发沙盘

一个纯前端、可安装、离线可用的PWA，用于模拟智能硬件从产品机会到上市复盘的完整Stage-Gate流程。

## 首版功能

- 多项目组合与健康度看板
- 14阶段智能硬件开发沙盘
- 20套专业AI文档提示词
- 竞品库与供应商资源池
- 需求—规格—测试追溯矩阵
- 项目交付件上传、版本、状态和本地归档
- 文档、竞品、供应商、需求和提示词全局查询
- JSON/Markdown项目交付包导出
- localStorage + IndexedDB本地数据存储
- Service Worker离线缓存与PWA安装

## 数据边界

首版不接入模型API，也不自动执行市场研究。用户复制系统生成的提示词到AI网页端执行，再把Markdown、JSON、PDF或Office结果上传回PWA。

市场规模、供应商报价、测试结果、认证结论、量产BOM和项目放行必须基于真实资料并由人工评审。
